# Glossary

- **Skill:** a folder with a `SKILL.md` that teaches Claude one job.
- **User-invoked:** a skill only you start, by typing `/` and its name.
- **Model-invoked:** a skill Claude starts on its own when your request matches its description.
- **Bucket:** a folder under `skills/` that groups skills by job and maturity.
- **Promoted:** in `operations/` or `productivity/`, so the plugin ships it.
- **Promotion gate:** the checks an item passes before it is promoted (see `CLAUDE.md`).
- **Readiness audit:** the `agent-readiness-audit` skill's pass or fail check against the Agent Readiness Standard.
- **Scrub check:** a search for employer, colleague and client names that must return nothing.
- **Leading words:** a short phrase repeated in a skill so the agent adopts the behaviour it names.
- **No-op:** text in a skill that changes nothing when deleted.
