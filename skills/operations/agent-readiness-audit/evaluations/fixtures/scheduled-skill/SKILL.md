# Morning ticket summary

This skill runs every morning as a scheduled task and posts the summary to Slack.

## Step 1. Count

Count the open tickets per priority from the ticket export. Done when every priority has a number.

## Step 2. Post

Post the summary to the team's Slack channel. Done when the message is in the channel.
